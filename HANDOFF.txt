Updated 24 October 2026 — Netlify migration

Current hosting for the new web features
- Intel public/member chat, Elite repricing, support submission and Vendex guides now use Netlify Functions with same-origin URLs. Existing Supabase login, membership and data are preserved.
- The Netlify deployment needs runtime SUPABASE_URL, SUPABASE_SERVICE_KEY, the existing GROQ_API_KEY (or ANTHROPIC_API_KEY), DISCORD_BOT_TOKEN and OWNER_DISCORD_ID. VENDORA_REPRICE_ENABLED=true activates the scheduler; each Elite member must separately opt in.
- Existing settings rows support atomic usage counters, job leases/cursors and reminder cooldowns. No SQL migration is needed. Functions fail closed when quota persistence fails.
- Reminder schedule: every ten minutes, processing only in the 12:10–12:59 London window with bounded batches. The Railway legacy runner is disabled by default to avoid competing delivery loops.
- Static deployment publishes dist/ with public assets only. Server code, tests and environment configuration are excluded from the public CDN.
- The original Vinted collector and older bot/API routes remain on the existing backend. The migration does not promise fresh data if that collector stops.
- Validation: 31 automated checks cover original features plus serverless routing, concurrent rate limits, access restrictions, input limits, consent and cooldowns. Build output is checked to exclude private sources.

Original feature notes

Changes
- Landing-page Intel launcher: charcoal pill, pink text/rim and soft pink hover/focus glow. Keyboard focus and reduced-motion support.
- Dashboard Intel: account and tool support on Basic (20 questions/day), read-only synced inventory guidance on Pro (60/day), repricing context and coach on Elite (120/day). Inactive accounts retain account/billing support (5/day).
- Server derives identity and active plan from verified Supabase authentication. Basic never loads inventory; Pro cannot access repricing. Banned accounts are blocked. No private data is added to public guides.
- Contact support opens the existing support form with a reviewable conversation excerpt. It does not automatically send a ticket.
- Elite repricing coach uses deterministic category asking-price evidence and active own-inventory listings observed for 14+ days. Old/failed inventory snapshots, stale/weak/mixed market data and unsuitable listings are skipped. No automatic price changes. Review model, condition, size and costs before changing a price.
- Optional Elite Discord reminders are off by default. Daily 12:10 Europe/London sweep; at most three suggestions per member per run, with a persisted seven-day per-listing cooldown and access/consent rechecks.
- /price-guides and /price-guides/<category> are server-rendered on the bot backend and proxied under vendora.site through Netlify. The hub lists categories with 7+ sampled days in the recent month, fresh data and a reasonably consistent price range. Thin/stale/widely mixed guides have noindex.
- Public guides include dated medians, middle ranges, daily history, sampling limits, related links, Dataset/BreadcrumbList metadata and a Discord trial CTA. Sitemap index combines existing pages with the dynamic guide sitemap.
- Previous complete week's price card is persisted in vendex_weekly_cards (four sampled days required). Guides export 1080x1350 PNGs for X/TikTok photo posts. Monday 09:15 Europe/London refresh plus first-request fallback.

Storage (existing settings table; no schema migration)
- reprice_preferences_<verified user UUID>: opt-in and change date
- reprice_sent_<verified user UUID>: last reminder timestamp by listing
- vendex_weekly_cards: public-only fixed weekly card values
- Uses existing niche_daily_v2 and vinted_inventory_<verified user UUID>

Deployment
- Frontend and Netlify redirects deploy from the existing main branch flow.
- Bot/backend must deploy the same change for new authenticated endpoints and server-rendered guides.
- No new runtime dependencies, environment variables or paid services.
- A category without sufficient real data will remain absent from the indexed library. No demo data is used in production.
- Existing niche observations do not identify exact sold comparables; guide and coach copy explicitly describe category asking prices.

Validation
- node --test tests/intelligence-and-guides.test.js
- node --check bot/index.js and browser assets; inline HTML scripts compile; git diff --check
- Browser preview uses local sample accounts and prices to check UI without sending live DMs or touching customer accounts.
